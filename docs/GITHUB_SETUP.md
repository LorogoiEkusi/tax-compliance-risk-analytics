# GitHub publication and Project Board setup

The project directory has been initialized as a local Git repository. No remote GitHub repository or live Project Board has been created yet because that requires access to the student's GitHub account and confirmation of the target repository name/visibility.

Suggested repository name: `tax-compliance-risk-analytics`

1. Create a new GitHub repository with that name (Public is suitable only after checking that no sensitive files are present; Private is safer during development).
2. Add the GitHub remote to this local repository and push the initial commit.
3. Create a GitHub Project using the Board layout.
4. Create columns: Backlog, Ready, In Progress, Review, Done.
5. Create four sprint iterations and import/create tickets from `github_project_board_tickets.csv`.
6. Add the project board link to the report and capture a screenshot showing sprint assignments and ticket statuses.
7. Keep raw source data and row-level customer data out of the remote repository.

The report's repository link field must be completed with the actual URL after publication. Do not submit a placeholder or invented URL.
